# Friday Flight

Rust製の、金星へ帰還するベクターワイヤーフレーム宇宙フライト。
外部画像・音楽ファイル・ネット接続は不要です。3D座標を透視投影した線画をGPUで描画します（物理的なベクタースキャンディスプレイ用出力ではありません）。

## 起動と配布

- Windows x64: `FridayFlight-Windows-x64.exe` をダブルクリック。
- Apple Silicon Mac: `FridayFlight.app` を起動。
- OSごとに実行ファイルが異なります。Windows版はクロスコンパイル済み。
- 公証はしていません。OSが初回起動の確認を表示する場合があります。

## フライト

**DEPART FOR VENUS**: 120秒。地球離脱 → 青い地球を振り返る → バンクしながら星の海を飛ぶ → 金星接近 → 白い光に包まれて大気圏突入 → 地表着陸。

**CHASE THE STARS**: 地球離脱後、宇宙空間を飛び続けます。隕石は遠くから迫り、機体のそばをすり抜けます。

| キー | 操作 |
|---|---|
| Space | 一時停止・再開（映像・BGM） |
| H | フライト中の文字・進捗表示を切替 |
| M | BGM ミュート・解除 |
| F | フルスクリーン切替 |
| Esc | タイトルに戻る |

BGMは92 BPM、マイナー7th／メジャー7thの循環、エレピ風の和音、ベース、メロディー、ブラシ風ノイズをリアルタイム合成したオリジナルです。BGMはフライトを新しく開始するたびに最初から流れ、着陸後も再生を続け、タイトル画面・一時停止中は停止します。音声デバイスが使えない場合は無音で動作します。


WindowsはCRTを静的リンクします。BGMとアイコンを含む全素材は実行ファイル内に内包されています。WindowsのOS標準ライブラリとGPUドライバは必要です。
